# D-014: 설정 변경 경로 — Config 단일화 (2026-03-23)

> Ante 설계 결정 기록.
> 인덱스: [README.md](README.md)
> 상태: D-018 이후 CLI/IPC 경로로 해석한다.

**결정**: 설정 조회·변경은 ConfigStore / DynamicConfigService 단일 경로로 처리한다. 별도 설정 저장소를 만들지 않는다.

**근거**:
- 이미 동적 Config 시스템(`ConfigStore` + `ConfigChangedEvent`)이 구현되어 있음
- 알림 설정, 시스템 설정 등 운영 설정 항목은 모두 `config` 테이블의 key-value로 표현 가능
- 별도 설정 저장소를 만들면 ConfigStore와 책임이 중복되어 혼란 유발
- `ConfigChangedEvent`를 통한 런타임 반영 메커니즘을 그대로 활용 가능

**영향 범위**:
- CLI/IPC: `ante config` 명령이 DynamicConfigService를 통해 동일 경로를 사용
