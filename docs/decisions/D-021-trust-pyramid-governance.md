# D-021: 신뢰 피라미드 기반 개발 거버넌스 (2026-11-18)

> Ante 설계 결정 기록.
> 인덱스: [README.md](README.md)
> 상태: **확정**
> 관계: D-019의 Gate A(`/code-review` 브랜치 리뷰) 적용 범위를 좁힌다. D-020의 수용 기준(스펙, CI 결과, 유지관리자 판단)을 전제로 한다. 이행은 에픽 [#2533](https://github.com/joshua-jingu-lee/ante/issues/2533)이 맡는다.

**결정**: 에이전트 교정은 지침 문장이 아니라 결정적 검사나 구조로 남긴다. 설계와 API, 린트·타입·테스트, 런타임 검증 순으로 신뢰를 쌓고, 산문 지침은 판단이 필요한 것만 둔다. 검사로 만들 수 없는 교정은 남기지 않는다.

**운영 원칙**:

- **Gate A 적용 범위**: 문서 전용 변경과 `src/`의 AST가 바뀌지 않는 변경(주석·독스트링만 고친 변경)에는 Gate A를 적용하지 않는다. 판정은 스크립트가 하고 CI 통과로 머지한다. 적용 범위의 정의는 [런북 04](../runbooks/04-ci-cd.md) §2 Gate A의 「적용 범위」에 있다.
- **브랜치 보호의 관리자 예외**: 유지한다. 브랜치 보호 설정은 바꾸지 않는다. main 보호는 pre-commit 훅으로 하고, 대표는 명시적으로 우회할 수 있다.
- **출력 봉투 통일의 버전 정책**: 0.x 안에서 한 번의 minor 릴리스로 일괄 전환한다. main에는 명령군 단위로 머지하고 `raw_legacy` 출력이 모두 옮겨질 때까지 릴리스하지 않는다. 전환 기간에는 ante-oracle과 조율한다.
- **post-merge 에픽 동기화**: post-merge 자동화의 에픽 체크리스트 동기화 경로를 삭제한다. 에픽 체크리스트는 하위 이슈가 닫힐 때 손으로 체크한다.
- **주석 금지**: `src/ante/**/*.py`의 `#` 주석과 독스트링 안의 이력 참조(이슈 번호, 리뷰 회차 등)를 금지한다. 허용은 규칙 코드를 명시한 도구 지시문(`# noqa: <규칙>`, `# type: ignore[<코드>]`, `# pragma: no cover`)과 셔뱅 줄뿐이다. 검사기와 기준선을 먼저 들이고 모듈 단위로 제거한다.
- **독스트링**: 이력 참조 금지와 총 줄 수 래칫을 먼저 두고, 주석 제거 뒤 길이 상한을 도입한다(private 함수 1줄, 모듈 3줄, public 함수·클래스 10줄, Click 도움말 예외).
- **지침 산문 동결**: 커맨드·에이전트·런북·스킬에 새 규칙을 추가하지 않는다. 지침 산문 줄 수가 기준선보다 늘면 CI가 실패하게 하고, 이미 워크플로가 강제하는 규칙과 규칙에 대한 규칙은 지운다.

**근거**:

- 문서 변경에는 실행해서 확인할 산출물이 없어 모든 문장이 반박 대상이 되고 LLM 리뷰가 수렴하지 않는다. 문서·프로세스 이슈에서 리뷰 회차가 수십 번까지 늘었다.
- 주석·독스트링만 고친 변경은 독스트링을 뺀 AST 동일성으로 동작 무변경을 증명할 수 있다. 수천 줄을 지우는 diff를 LLM이 읽는 것보다 검증 결과로 판정하는 편이 정확하고 싸다.
- 구조로 막은 부류는 재발하지 않았다. 인증 누락은 기본 거부 미들웨어(D-015) 한 번으로 사라졌지만, 건별로 고친 입력 검증 누락은 계속 쌓였다.
- 주석과 산문 지침은 강제할 수 없고 낡는다. 교정을 문장으로 남기면 지침이 계속 두꺼워지고 일부는 서로 겹친다.

**검토한 대안**:

- **모든 변경에 Gate A 유지**: 문서·프로세스 이슈가 리뷰에서 수렴하지 않는 비용이 계속되므로 채택하지 않는다.
- **리뷰 범위를 파일 단위로 좁혀 `/code-review`에 넘기기**: 리뷰 대상이 여전히 diff이고 판정이 복잡해지므로 채택하지 않는다. 판정은 PR 단위로 한다.
- **브랜치 보호에서 관리자 예외 제거**: 대표의 명시적 우회 경로가 사라지므로 채택하지 않는다. main 보호는 pre-commit 훅으로 한다.
- **출력 봉투를 명령군마다 릴리스하며 전환**: 소비자가 중간 상태의 혼합 봉투를 여러 번 겪으므로 채택하지 않는다.
- **주석을 남기고 내용 규칙만 두기**: 내용 규칙은 검사로 강제할 수 없으므로 채택하지 않는다.
