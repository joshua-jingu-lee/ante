# 알림 이벤트 정의 (Notification Events)

Bot 모듈이 발행하는 `NotificationEvent` 목록. `bot/manager.py`에서 직접 발행한다 (category: `"bot"`).

### 봇 시작

**트리거**: 봇 정상 가동 완료 시
**데이터 수집**: bot_id, 전략명, 전략 버전

```
ℹ️ 봇 시작
봇 bot-001이 가동되었습니다.
전략: momentum_breakout v1.0.0
```

### 봇 중지

**트리거**: 봇 정상 중지 시 (수동 또는 시스템 종료). 미체결 주문의 정리가 끝난 뒤에 나간다([03-design-decisions.md](03-design-decisions.md) 「정지 때의 미체결 주문」). 텔레그램 `/stop`의 정지는 이 알림 대신 응답에 같은 내용을 적는다.
**데이터 수집**: bot_id, 취소한 미체결 주문 수, 취소에 실패한 주문 수, 만료한 스탑 주문(종목·방향·스탑 가격)

```
ℹ️ 봇 중지
봇 `bot-001` 중지 완료
미체결 주문 취소: 2건 (실패 1건)
스탑 주문 만료: 1건
- 005930 sell stop 68,000
```

정리를 하지 않는 정지(서버 종료)는 첫 두 줄만 적는다.

### 봇 에러

**트리거**: 봇 실행 중 예외 발생 시
**데이터 수집**: bot_id, 에러 메시지

```
❌ 봇 bot-001에서 에러가 발생
Connection timeout after 30s
봇은 자동 재시작을 시도합니다.
```

### 재시작 한도 소진

**트리거**: 자동 재시작 최대 횟수 도달 시
**데이터 수집**: bot_id, 재시작 시도 횟수, 마지막 에러 메시지

```
❌ 봇 bot-001이 3회 재시작에 모두 실패했습니다
마지막 에러: Broker API 연결 실패
봇이 중지 상태입니다. 원인 확인 후 수동 재시작하세요.
```

### 봇 자동 재시작 중단

**트리거**: 쿨다운 뒤 계좌 조회가 실패해 자동 재시작을 하지 않을 때, 그 봇이 아직 에러 상태로 등록돼 있으면 낸다 (쿨다운 중 수동 시작·중지·삭제된 봇에는 내지 않는다. 계좌가 활성 상태가 아니라서 건너뛸 때는 내지 않는다 — 정지 시점의 알림이 이미 있다)
**데이터 수집**: bot_id, account_id

```
❌ 봇 자동 재시작 중단
봇 bot-001 · 계좌 acc-001
계좌를 확인하지 못해 자동 재시작을 하지 않았습니다. 봇은 에러 상태로 남습니다. 원인 확인 후 수동으로 다시 시작하세요.
```
